# 🐾 Zasady Współpracy - Projekt ZOO 🐘

Witaj w zespole! Cieszymy się, że chcesz pomóc w tworzeniu naszej strony o zwierzętach z zoo. Aby nasza współpraca przebiegała gładko i sprawnie, prosimy o trzymanie się poniższych zasad.

## ❓ Jak mogę pomóc?

Masz pomysł na nowe zwierzę do opisania, nową funkcję lub znalazłeś błąd? Świetnie!

1.  **Zgłaszanie błędów lub pomysłów:** Użyj zakładki **"Issues"** na GitHubie, aby opisać swój pomysł lub znaleziony błąd. Opisz go jak najdokładniej.
## 🔧 Praca nad kodem - Krok po kroku

Stosujemy prosty przepływ pracy oparty o gałęzie (branches). **Nigdy nie wysyłamy zmian bezpośrednio do gałęzi `main`!**

1.  **Stwórz nową gałąź (branch):**
    Zawsze twórz nową gałąź (branch) dla zadania, nad którym pracujesz. Nazwa powinna być krótka i opisywać, co robisz. Używaj angielskich nazw, bez polskich znaków i spacji (używaj `-`).
2.  **Pracuj lokalnie:**
    Wprowadzaj zmiany w plikach HTML, CSS, dodawaj zdjęcia itp.
3.  **Zatwierdź zmiany (Commit):**
    Rób częste, małe commity. Każdy commit powinien dotyczyć jednej, logicznej zmiany.
4.  **Wypchnij gałąź (Push):**
    Gdy skończysz pracę (lub na koniec dnia), wypchnij swoją gałąź na GitHub.
5.  **Utwórz Pull Request (PR):**
    Wejdź na stronę repozytorium na GitHubie. Zobaczysz żółty pasek z propozycją utworzenia **Pull Request** (PR) dla Twojej nowej gałęzi. Kliknij go, opisz krótko, co zrobiłeś i poproś o przejrzenie kodu (review).

## 📜 Standardy Kodu

Trzymamy się tych zasad, aby nasz kod był czysty i spójny.

### 2. Kod HTML
* Używamy semantycznego HTML5 (np. `<nav>`, `<section>`, `<article>`, `<footer>`).
* Używamy wcięć (2 lub 4 spacje) dla czytelności.
* Wszystkie obrazki `<img>` **muszą** mieć atrybut `alt` (opis alternatywny).
* Nazwy plików piszemy małymi literami, bez spacji (np. `strona-lwa.html`).
### 3. Kod CSS
* Jeśli to możliwe, trzymajmy style w oddzielnym pliku `.css` (np. `style.css`), a nie wewnątrz tagów `<style>` w HTML.
* Używajmy logicznych, angielskich nazw dla klas (np. `.animal-card`, `.main-navigation`).
### 4. Pliki i Foldery

* Wszystkie zdjęcia zwierząt trzymamy w folderze `/images`.
* Wszystkie pliki CSS trzymamy w folderze `/css`.
* Wszystkie pliki HTML trzymamy w głównym folderze (lub w podfolderach, jeśli strona się rozrośnie).
